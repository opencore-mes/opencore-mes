A connection is another system the plant's services may send requests to: its address, how they sign in to it, and the only requests allowed. A service uses it only once it ticks it on its Reaches tab, approved by this connection's stewards. On a live design, or a change you may not edit, every control here is read only.

Its tabs

The tabs
General opens first. Click a tab to see its settings; the open one is highlighted.
A number on a tab
How many things on that tab differ from the live version. On Changes, the total.
Remove, and Undo
Every Remove asks first. What is removed leaves this change only; nothing live changes until the change executes, and Undo (⌘Z or Ctrl+Z) brings it back.

Copilot

The conversation
Ask the AI to draft, check or explain the connection. It works as you, saves into this draft, and never submits. The conversation is kept with the change: it picks up here any time.
Ask the copilot…
Type what you want. ⌘ Enter or Ctrl+Enter sends; you can paste or drop a file into the box.
Attach
Adds a picture, a PDF, a CSV file or an Excel workbook (up to 5); × on a file takes it off.
Send
Saves your unsaved edits first, then sends. Greyed out while it works, or when no AI is set up.
New conversation
Asks first, then deletes the conversation kept with this change. The draft stays as it is.

Changes

The differences
What this change does to the connection against the live version, grouped by tab: how many changed, were added and removed. Reviewers and approvers see the same.
Open …
Jumps to the tab where that group is edited.
A difference
Marked new, changed or removed; click it to open or close it. Lines marked − are the live version's, lines marked + the draft's.

General

Name
Fixed once created: services name the connection by it.
Label
A text field: what people know it by. Required.
Base URL
An http:// or https:// address, with no user, password, query or fragment. Every request goes here and stays here: redirects are not followed.
Timeout (ms)
How long a request may take before it fails: 100 to 30 000 milliseconds (5 000 unless you change it).

Authentication

Kind
A drop-down: none; bearer (an Authorization: Bearer header); header (a header of your choice); or basic (user and password).
Secret
For any kind but none: the name of the secret that holds the credential (lower case, digits, _). Its value is set on the server (MES_SECRET_<NAME>) and never appears in a design, a review or the audit.
Header
For the header kind: the header that carries the credential, such as X-API-Key.

Allowed requests

The requests
The only requests a service may send this system, one row each. Anything not listed is refused, and the refusal is logged. At least one is needed.
Method
A drop-down: GET, POST, PUT, PATCH or DELETE.
Path
Starts with /, after the base URL. Ending it with * allows what follows: /orders/*.
Remove
Takes the request out, after asking.
Add request
Adds a row, POST /, to change.

Activity

Refresh
Fetches the latest calls again.
Calls
The latest service runs that sent this system a request: when, as whom, the outcome (with the error), how the service was set off, each request and its status, and how long it took.

Stewards

Departments
Tick each department that approves every change to it: its address, its authentication and the requests it allows. A service that starts using it is approved by them too.

JSON

The connection as JSON
All of it as data, for integrators. Edit it here, then apply it.
Apply JSON
Replaces the draft with it; every check runs as on any other edit. Its name must stay the same; what is wrong is said in red beside the change.
