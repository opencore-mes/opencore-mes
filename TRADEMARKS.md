# Trademarks

**OpenCore MES** and the OpenCore MES logos are trademarks of [Full legal name]. The code
is open source ([LICENSING.md](LICENSING.md)); the name and logos are not. This policy lets the
community talk about OpenCore MES freely, while making sure that whatever carries the name is the real
thing.

## You may, without asking

- Say that your product, service or fork is **"built on OpenCore MES"**, **"based on OpenCore MES"** or
  **"compatible with OpenCore MES"**, when it is true.
- Name OpenCore MES in articles, talks, courses, comparisons and reviews.
- Distribute an **unchanged** copy of the community edition under its name, with its notices.
- Use the name in a community event or user group about OpenCore MES, if it is clear the event is not
  run by the OpenCore MES project ("an OpenCore MES user group").

## You may not, without written permission

- Name a changed version, a fork, a product or a service "OpenCore MES", or a name close
  enough to be confused with it ("OpenCore MES Pro", "OpenCoreMES-x").
- Use the logos, except to point to the official project.
- Suggest that the project endorses, certifies or supports your product or service.
- Use the name in a company name, a domain name or a social media handle.
- Sell anything as an "OpenCore MES suite": the suites are the project's own products.
